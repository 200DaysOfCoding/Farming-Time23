# 100 Days of Coding Challenge

## 🚀 Vision générale

Bienvenue dans mon défi personnel de programmation sur 100 jours! Ce projet documente mon parcours d'apprentissage intensif en développement web, structuré comme un programme d'étude progressif. En tant qu'étudiant en 3ème année de génie logiciel, je renforce mes compétences existantes tout en explorant de nouvelles technologies et méthodologies pour devenir un développeur plus complet.

## 📋 Structure du défi

Ce défi est divisé en 5 phases principales, chacune se concentrant sur des aspects spécifiques du développement:

### Phase 1: Consolidation des fondamentaux (Jours 1-20)
- Approfondissement de HTML5/CSS3 avec Bootstrap 5
- JavaScript moderne (ES6+)
- Introduction à Python et ses fondamentaux
- Responsive design avancé avec Bootstrap Grid System
- Git & GitHub workflows professionnels
- Principes d'accessibilité web

### Phase 2: Frontend avancé (Jours 21-40)
- Maîtrise d'un framework frontend (React)
- Intégration de Bootstrap avec React (ou React Bootstrap)
- Gestion avancée des états
- Python pour le frontend (visualisation avec Dash ou Streamlit)
- Tests automatisés frontend
- Optimisation des performances
- Animations et transitions sophistiquées

### Phase 3: Backend et bases de données (Jours 41-60)
- Développement avec Node.js/Express ET Python (Django/Flask)
- Conception d'API RESTful avec les deux technologies
- Systèmes de bases de données (SQL et NoSQL)
- Python pour la science des données (pandas, numpy)
- Sécurité et authentification
- Architecture serveur scalable

### Phase 4: Développement Full Stack (Jours 61-80)
- Applications full stack intégrées (JavaScript & Python)
- Pipeline CI/CD et déploiement continu
- Services cloud (AWS/Azure/GCP)
- Python pour l'automatisation et le scripting
- Fondamentaux DevOps
- Progressive Web Apps (PWA)

### Phase 5: Projet final et spécialisation (Jours 81-100)
- Réalisation d'un projet complet de bout en bout (combinant Python et technologies web)
- Machine Learning avec Python (introduction)
- Construction d'un portfolio professionnel avec Bootstrap
- Applications web avec analyse de données intégrée
- Revue de code et optimisations avancées
- Documentation de niveau production

## 🎯 Objectifs principaux

- **Consistance**: Coder et apprendre au moins 1 heure chaque jour pendant 100 jours consécutifs
- **Progression**: Suivre un parcours d'apprentissage structuré avec des défis de difficulté croissante
- **Documentation**: Enregistrer quotidiennement les progrès, apprentissages et défis rencontrés
- **Application**: Transformer les connaissances théoriques en projets concrets
- **Polyvalence**: Développer des compétences variées couvrant l'ensemble du cycle de développement
- **Portfolio**: Constituer un portfolio de projets démontrant mes compétences aux employeurs potentiels

## 🛠️ Projets prévus

1. **Portfolio personnel développeur** (Phase 1)
   - Site vitrine responsive utilisant Bootstrap 5
   - Script Python pour générer dynamiquement du contenu du portfolio

2. **Application de gestion de tâches** (Phase 2)
   - Application frontend avec React et Bootstrap
   - Dashboard de visualisation des tâches et statistiques avec Python (Dash ou Plotly)

3. **Système de gestion de données** (Phase 3)
   - API REST avec Node.js/Express et une version alternative avec Flask/Django
   - Scripts Python d'analyse de données et reporting automatisé
   - Backend complet avec authentification et base de données

4. **Application full stack de e-commerce** (Phase 4)
   - Plateforme complète avec panier, paiement et gestion de comptes
   - Système de recommandation de produits avec Python
   - Automatisation des tests et du déploiement avec scripts Python

5. **Projet final d'intelligence artificielle appliquée au web** (Phase 5)
   - Application web intégrant un modèle de ML développé avec Python
   - Interface utilisateur moderne avec Bootstrap et React
   - Système complet de bout en bout démontrant l'intégration des technologies web et Python
